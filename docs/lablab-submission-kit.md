## 1) Basic Information

### Project Title
DataReady: Gemini-First BI Truth Audit

### Short Description
DataReady is a Gemini-first, multimodal audit app that detects why BI reports are wrong before teams ship AI copilots.

### Long Description
DataReady is an enterprise-focused AI readiness system for BI and analytics teams.  
It starts from a real report problem, then audits CSV data with optional dashboard screenshots and dictionary PDFs to find semantic-layer failures that break AI BI experiences.

Core workflow:
1. Profiler (Gemini Pro + Flash + deterministic grounding)
2. Business Logic Validator
3. Remediation Planner
4. Readiness Scorer

DataReady outputs:
- readiness score + confidence + evidence coverage
- evidence-backed root-cause ranking
- business impact summary
- fix pack (SQL / dbt tests / Power Query / semantic notes)
- shareable export bundle

Practical value:
- catches report correctness issues early
- improves AI BI rollout safety
- gives BI owners handoff-ready remediation steps

Gemini alignment:
- uses Gemini for reasoning and multimodal understanding
- supports agent-driven multi-step workflows
- delivers a working prototype with measurable business utility
